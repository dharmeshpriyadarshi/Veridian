Candidate 1: CPCB AQI Repository {
    The most authoritative source is the official CPCB AQI repository. CPCB provides AQI and pollutant monitoring data through its national monitoring network.
    Useful because:
    ✅ Official Government of India source
    ✅ Real monitoring stations
    ✅ AQI + pollutant measurements
    ✅ Continuously updated
    Potential downside:
    ❌ Data extraction and cleaning can be painful
    ❌ May require assembling datasets yourself
    If this project were a research paper, this would be my first choice.
}

Candidate 2: Rohan Rao CPCB Dataset {

    Air Quality Data in India (2015-2020)
    Important detail:
    The dataset is sourced from CPCB public data.
    Advantages:
    ✅ Widely used
    ✅ Real data
    ✅ Many research projects use it
    ✅ Easier than scraping CPCB
    Disadvantage:
    ❌ Stops around 2020
}

Candidate 3: OpenAQ {

    OpenAQ aggregates government and research-grade air quality data globally and includes pollutants like PM2.5, PM10, SO₂, NO₂, CO and O₃.
    Advantages:
    ✅ Real data
    ✅ API access
    ✅ Global
    ✅ Includes meteorological variables in some cases
    Disadvantages:
    ❌ Requires API work
    ❌ Data structure is more complex
    For a student project this is powerful but adds engineering complexity.
}
